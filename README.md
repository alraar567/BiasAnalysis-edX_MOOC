# BiasAnalysis-edX_MOOC

This repository contains the code of the study presented in the paper *Pedro Manuel Moreno-Marcos, Alicia Ramirez-Arrabe, Carlos Alario-Hoyos, Pedro J. Muñoz-Merino, Iria Estévez-Ayres, and Carlos Delgado Kloos. 2026. Analysis of Bias in Student Modelling and Prediction Using Learning Analytics on edX MOOC Data. In Proceedings of the Learning Analytics Summer Institute Spain 2026, Zamora, Spain, May 2026 (LASI SPAIN '26)*.

The  study analyzes possible biases that appear when estimating ability and difficulty of exercises with IRT, and when developing predictive models. The analyses were carried out using data from a MOOC about Java programming hosted in edX in a synchronous mode. The course was structured in five weeks, and each of them had a graded exam, with 5-8 exercises each. In addition, the course contained several videos per week and formative exercises (135 in total). In order to pass the course, students needed to get 60% of the points at least, and 88,324 users performed at least one action in the course.
